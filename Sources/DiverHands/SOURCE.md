# Unity 手模型来源（原件不随公开仓库分发）

项目手模型来自 Unity XR Hands HandVisualizer 样例的 `Models/LeftHand.fbx` 与 `RightHand.fbx`。两只模型及 26 关节骨架未改，项目仅另设 `.meta` GUID、追踪驱动和海底材质。

来源记录对应 XR Hands 1.7.3 HandVisualizer，已核对两只模型与该包及较早 1.4.1 样例的字节均一致；当前运行时依赖为 1.7.3。使用者需从自己已获许可的包恢复，哈希和脚本见 [DEPENDENCIES.md](../../docs/DEPENDENCIES.md)。不复制样例原 `.meta`，不替换项目 GUID。
