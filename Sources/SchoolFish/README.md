# Polyy.AI 鱼模型与群游衍生

来源：[Polyy.AI 3D Fish Pack](https://polyyai.itch.io/3d-fish-pack)，作者 Polyy.AI。原作者页在本次公开导出复核时标注 CC0 1.0 Universal / public-domain dedication，并允许商业、免费游戏、改制和合辑。作者同时另列以下原句：

> Don't resell unmodified.

其说明针对把原始文件包装成自己的模型商品出售。本次分发为免费游戏工程，群游模型还经过减面；不出售未改模型包。本记录忠实保留作者的 CC0 标注和该单独说明，不将整工程其他资源重新声明为 CC0。原作者披露 AI-assisted graphics；这些是美术鱼模型，不是科学形态扫描。

当前 `Assets/Resources/Fish/`保留海洋环境所用 GLB。原包为静态、无 rig/动画的模型，底色和 metallic/roughness 嵌入，程序游动由项目实现。巨鲲使用其中 `16_manta_ray`的幻想化衍生。

`Assets/Resources/SchoolFish/`的三份衍生为小型鱼群层：`01_clownfish`约 800 三角形、`02_blue_tang`和 `23_mandarinfish`约 799 三角形。使用保留 UV 的减面、法线重算和顶点去重，保留原材质与原坐标/尺度；不虚构法线贴图。近景鱼与小鱼群的资源和行为不是同一模型精度声明。

未使用的淡水模型及旧备用鱼原件不包含在此公开仓库；不因此修改现有保存档的永久身份。
