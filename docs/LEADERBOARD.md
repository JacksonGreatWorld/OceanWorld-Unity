# 本版排行榜关闭说明

**2.9.11 / code304 不提供积分榜、生物发现榜、昵称编辑或自动联网同步。** 本版无需服务器地址；正常玩法、关卡、收藏、观察图鉴与成就使用本地记录。

## 当前行为

- 生产菜单不创建排行榜按钮，历史按钮回调也不能弹出榜单或改变游泳暂停状态。
- 客户端不解析发布地址、不创建签名身份或后台签名任务、不读取展示旧服务器昵称，也不启动排行、能力探测、成绩上传或发现上传请求。
- 已有本地关卡、收藏、观察与成就原件保留。旧排行榜账本的累计事实仍可供本地成就读取，旧昵称和待上传事件留在文件中，不重新绑定身份、不伪造确认、不自动上传。
- 新的贝壳、鱼与金币收集继续持久化本地累计及去重身份，不向历史待上传队列追加事件。因此旧队列满不会成为新收集或换关的网络障碍。账本损坏等真实持久化故障仍需保留原件并处理，不承诺忽略存储失败。
- 观察图鉴由独立的本地观察档负责记录；它不会在关闭模式写入历史发现上传队列。

## 构建输入

当前Android构建必须不含 `Assets/Resources/PrivateRelease/` 目录或 `OceanLeaderboardConfig.json`。关闭版的构建检查会拒绝这些输入，不能通过注入地址将本候选变成联网发行版。配置辅助脚本也会拒绝对当前关闭版恢复配置。

仓库不包含生产服务地址、服务器账号、签名私钥或玩家数据。旧本机配置应在工程之外安全保管，不加入Git，也不作为本版APK资源。重建前按[依赖说明](DEPENDENCIES.md)取得SDK与手模型；无需配置排行榜服务。

## 保留的历史架构

源码仍保留HTTPS协议、配置校验、平台签名与身份冲突防护，便于维护旧数据；这些代码的存在不代表当前版本启用了网络能力。公开版原有 `OfflineOnly` 与 `IdentityMigrationRequired` 防护继续保留。

若将来开发独立联网服务，需要单独完成服务器、内容审核、隐私说明、身份与历史数据迁移，以及真实设备端到端验证。旧随机本地身份不能静默改绑为新的平台签名身份；不得清理旧证据、伪造服务器确认或将历史成绩冒充新身份。APK中的请求目的地也不能靠隐藏地址代替服务端权限校验。

## 验证范围

当前公开候选已通过Unity编译与完整Editor回归；其中排行榜关闭检查通过1,212项，公开配置与Android设置检查通过10项。它们覆盖菜单与旧动作、无身份和请求任务、本地满旧队列计分、重启去重、历史字段保留及成就补认，使用独立临时合成历史，不连接真实服务，不修改玩家数据。独立Gradle工程的code304本地基线构建成功，最终预编译APK仍在核验；这不是当前公开源码提交与APK字节对应的证明，安装、双目和佩戴亦未完成验收。完整范围见[验证记录](VALIDATION.md)。
