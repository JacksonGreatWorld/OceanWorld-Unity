# 联网排行榜与发布配置

排行榜是游戏功能的一部分。公开源码保留联网能力，生产服务配置与服务器管理凭证不公开。

## 玩家行为

- 积分榜：有效贝壳收集1分，鱼类与成功捕获鲨鱼2分，金币10分。射击命中次数本身不加积分；重复上传不重复计分。
- 生物发现榜：跨关累计发现的不同物种数量，独立于积分榜。当前开放图鉴与历史永久身份的分母由物种目录协议区分，不能将历史身份数量写成当前可观察数量。
- 昵称支持中文和拼音输入；离线修改先保存草稿，联网由服务端检查重名、确认后生效。
- 排行榜使用游标连续翻页；没有网络时显示已缓存信息并区分缓存与实时数据。
- 成绩与发现记录先落盘；恢复网络后自动重试，只在有效服务端确认后移出待同步队列。队列有4,096条上限，长时间离线且达到上限会拒绝新增积分事件，不能承诺无限离线队列。

## 本机私有配置

在仓库以外的私有文本文件中保存自己的HTTPS API根地址（单行、无账号密码、查询参数或片段）。然后在仓库根目录预检：

```sh
python3 Scripts/configure-leaderboard.py --base-url-file /private/path/ocean-api-url.txt
```

核对后显式写入：

```sh
python3 Scripts/configure-leaderboard.py --base-url-file /private/path/ocean-api-url.txt --apply
```

也可用`--base-url`传入自己的地址，或通过`--project`指定本地Unity工程。请勿在公开日志、截图、命令示例中使用真实部署地址。

脚本不联网、不下载依赖、不接受密码，只创建缺失且合法的配置；已有相同内容会验证，已有不同内容会拒绝覆盖。目标为`Assets/Resources/PrivateRelease/OceanLeaderboardConfig.json`，仅含`baseUrl`，整个目录及其Unity元数据被Git忽略。不要强制加入Git或上传证据目录。该资源供预期的Player构建读取；APK中的客户端目的地无法被保证永远隐藏，访问控制依靠HTTPS、设备签名和服务端校验，服务端管理口令始终留在服务器。

克隆后不配置即可在Editor检查本地玩法；联网发行前必须准备正确服务配置。非Development Android构建缺失或损坏配置会明确失败，防止误发没有联网功能的包。VibeLab或CI构建也需要在其私有构建环境中注入此配置，不能只填仓库链接便假定能访问现有服务。

## 身份、数据与安全

设备身份继续由Android Keystore中的设备端密钥生成，客户端只发送公钥和签名，不包含服务器管理密码。Editor测试身份不能连接正式服务。保持平台默认TLS校验，不跳过证书校验或降级为HTTP。

首轮公开离线快照曾使用随机本地身份。如果使用者已经从该旧快照自行构建并产生进度，恢复联网时可能遇到与Keystore身份不一致的账本：原件必须保留，不能静默重绑、清数据、伪造服务器ACK或将旧积分冒充新签名身份。本轮不承诺自动迁移这些身份。原内部体验包一直使用原签名身份，未被本次公开副本修改。

## 验证边界

2026-10-21只读检查：使用本机已存在的受信CA及正常主机验证，能力接口HTTP200；系统curl默认TLS检查也HTTP200。初次Python失败来自其CA集合为空，未绕过验证或修改服务器。该检查没有发送昵称、成绩、收藏或测试事件。

能力接口可达不等于本轮已实测签名上传、重名冲突、完整多页排行和断网恢复。公开联网副本仍需配置发布环境、重新构建APK并在头显上验收；不得把既有内部APK当成新公开源码的构建。最新代码和Editor检查状态见[验证记录](VALIDATION.md)。
