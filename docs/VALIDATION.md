## 构建与体验边界

- 本公开副本尚未生成Android APK；当前验证机的该Unity安装未带Android Build Support。请按依赖文档安装匹配模块后构建。
- 既有PICO候选包包含原服务逻辑，不能当作本公开离线源码的对应构建。仓库不附带该APK。
- 本次未执行PICO佩戴验收、Quest真机测试、GPU/双目特效或持续帧时验证。编辑器导入或逻辑通过不能证明这些表现。
- 本地账本沿用有界事件队列（4,096条）；公开版不会伪造服务器ACK。大量反复游玩达到该边界时，后续积分记录可能被拒绝，长期纯离线账本压缩仍待完善。

## 本地复查

安装依赖后，可在Unity菜单运行 `OceanWorld/Validation/Public offline edition` 和 `OceanWorld/Validation/First twenty player content`。测试使用隔离临时账本，不应以测试进度覆盖玩家存档。

公开检查器扫描的是准备提交的干净内容树，不应把本机恢复的SDK、手模型、Library缓存或私有验收日志纳入待发布目录。脚本用法：

```sh
python3 Scripts/check-public-release.py --help
```

报告应写到仓库以外。保留失败记录；仅当实际检查通过后才能将其写成完成。
