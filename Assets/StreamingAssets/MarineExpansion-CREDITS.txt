Game adaptation by OceanWorld: imported the original Generic skinned FBX;
selected and looped its authored Swim clip; disabled root motion; used separate
uniform navigation scale and an anatomical heading wrapper. Original animation
curves and original downloadable archive were retained without editing.
The original 800 x 534 source images are retained unchanged. Runtime images
use an edge-padded 800 x 536 canvas with compensating UV scale. Base-color RGB
uses native ASTC 4x4; its alpha is set to 255 for the opaque game material.
The original normal-map X/Y channels are retained losslessly in native RGBA32
AG packing; the shader reconstructs Z. URP material roughness is a game-selected scalar;
no source roughness map was supplied. These conversions do not imply author
endorsement. See OceanMarineCompanions-credits.txt for the turtle and dolphin.
